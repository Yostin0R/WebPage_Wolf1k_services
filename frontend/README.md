# WOLF1K Services — Frontend

React 19 + Vite + TypeScript + MUI. Ver el [README principal](../README.md) para instalación,
variables de entorno y la guía para agregar contenido.

```bash
cp .env.example .env
npm install
npm run dev        # desarrollo
npm run build      # producción (dist/)
npm test           # tests
npm run lint       # ESLint
```
